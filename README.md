# SVG online kodieren

Ein kompaktes Browserwerkzeug, das SVG-Code für CSS und Data-URIs aufbereitet und direkt als Vorschau darstellt.

**Live:** [svg.moritzvollmer.de](https://svg.moritzvollmer.de/)

## Funktionen

- SVG-Code URL-konform kodieren
- CSS-`background-image` erzeugen
- Data-URI und CSS direkt kopieren
- Ergebnis unmittelbar in einer Vorschau kontrollieren

## Technische Basis

React, JavaScript, CSS und Vite. Die Verarbeitung findet vollständig lokal im Browser statt.

```sh
npm install
npm run dev
npm run build
```
